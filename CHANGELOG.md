### Added
- Initial project structure for BlackBeam microservices system.
- ApiGateway service using YARP.
- Identity service with JWT authentication and MySQL integration.
- Inventory service.
- Loyalty service.
- Orders service with Stripe integration and SignalR Hub for real-time tracking.
- Shared class library containing enumerations and standard response models.
- Environment configuration files (`.env`) for managing sensitive credentials.
